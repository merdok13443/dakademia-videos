# Dakademia: Privacy Policy

The Dakademia publishing tool (the "App") is a private tool of one account owner. It connects only to the project's own
TikTok account (@dakademia.il) through TikTok Login Kit and the Content Posting API (scope video.upload).

- **What the App receives:** an access token for the owner's own account, and the basic profile id that TikTok returns on login.
- **What the App does with it:** uploads the project's own video files to the owner's TikTok inbox as drafts.
  The login token is kept encrypted in a private automation setting, is used only for this upload, and is never shared.
- **What the App does not do:** it does not collect, store or sell personal data of viewers or any other person,
  does not read the owner's messages or videos, and does not use any data for advertising.
- **Retention and deletion:** the owner can revoke the App at any time in TikTok settings (Security and permissions,
  Apps and services). After that the stored token stops working and is deleted.

Contact: through the Dakademia account on TikTok (@dakademia.il) or Instagram (@dakademia.il).

# דקדמיה: מדיניות פרטיות

כלי הפרסום של דקדמיה ("האפליקציה") הוא כלי פרטי של בעל חשבון אחד. הוא מתחבר רק לחשבון הטיקטוק של הפרויקט (@dakademia.il)
דרך Login Kit של טיקטוק וה-Content Posting API (הרשאה video.upload).

- **מה האפליקציה מקבלת:** אסימון גישה לחשבון של הבעלים עצמו, ומזהה הפרופיל הבסיסי שטיקטוק מחזירה בהתחברות.
- **מה היא עושה בזה:** מעלה את קבצי הווידאו של הפרויקט לתיבת הדואר של הבעלים בטיקטוק כטיוטות. האסימון נשמר מוצפן
  בהגדרה פרטית של האוטומציה, משמש רק להעלאה הזו, ואינו משותף עם אף אחד.
- **מה היא לא עושה:** לא אוספת, לא שומרת ולא מוכרת מידע אישי של צופים או של אדם אחר, לא קוראת הודעות או סרטונים של הבעלים,
  ולא משתמשת בנתונים לפרסום.
- **שמירה ומחיקה:** הבעלים יכול לבטל את ההרשאה בכל עת בהגדרות טיקטוק (אבטחה והרשאות, אפליקציות ושירותים). אחר כך האסימון
  השמור מפסיק לעבוד ונמחק.

יצירת קשר: דרך חשבון דקדמיה בטיקטוק (@dakademia.il) או באינסטגרם (@dakademia.il).
